# RS3 Low HP Hiscores

[View the leaderboard](https://tastyromeo.github.io/hiscores/)

To edit usernames, change the file [data/username_inbox.csv](data/username_inbox.csv), one line per change. Changes apply on the next update:

- `old_name,new_name` to update an existing username;
- `,new_name` to add a new username;
- `old_name,` to remove an existing username.
